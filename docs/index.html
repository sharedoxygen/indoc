The Honest Distinction

Why This Isn't Just RAG With Extra Steps

Before — RAG

Retrieve → Stuff Context → Answer

One retrieval, one generation. A fixed pipeline. The model never decides what to do next — it's handed documents and writes a reply.

Now — Agent

Plan → Act → Observe ↺ Re-Plan → Answer

The model chooses each tool call from what it has learned, chains steps, and stops when it has enough evidence. That decision loop is what "agentic" means.
